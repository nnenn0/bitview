# bitview for VS Code

`.bitview` ファイルのための VS Code 拡張機能。マーケットプレイスには公開しておらず、手元でパッケージにして入れる。

- ハイライト: HTML 要素の関数、定義した関数、組み込み関数（`map`・`concat`）、キーワード、レコードのキー、フィールド、文字列、コメントを色分けする。
- 編集: `--` のコメントの切り替え（Cmd+/）、括弧の補完、`entry-list` を1語として扱う単語の区切り。
- 定義へ移動（F12、Cmd+クリック）: 関数名は、開いているファイルが属するプログラムの `.bitview` から定義を探す。genbit と同じく、最も近い祖先の `views/` の配下全体を1つのプログラムとする（`views/` の外では、ファイルのあるディレクトリ）。フォルダを開かずにファイルだけを開いても使える。引数名は、それを宣言した関数の引数へ移動する。`.` の後のフィールドとレコードのキーは対象外。
- 参照を検索（Shift+F12）: 関数なら同じプログラムの全 `.bitview` から、引数ならその関数の中から、名前を使っている箇所を探す。定義の名前の上で Cmd+クリックしても参照の一覧が出る。同じ名前の引数が隠している箇所、フィールド、レコードのキー、文字列とコメントの中は含まない。
- アイコン: `.bitview` ファイルに `<λ>` のアイコンを付ける（HTML の山括弧と、関数を表すラムダ）。使っているファイルアイコンのテーマが `.bitview` 用のアイコンを持たない場合（標準の Seti など）に表示される。
- シンボル: アウトライン、ファイル内のシンボル（Cmd+Shift+O）、ワークスペースのシンボル（Cmd+T）。

定義の検出は `fn 名前(` の正規表現で行う。1つのプログラムの `.bitview` は1つの名前空間を共有するので、名前から定義が1つに決まる。ワークスペースのシンボル（Cmd+T）だけは、ワークスペースの全 `.bitview` を対象にする。

## インストール

```sh
cd editors/vscode
npx @vscode/vsce package --no-dependencies --skip-license -o bitview.vsix
code --install-extension bitview.vsix
```

更新したときも同じ手順で入れ直す。
