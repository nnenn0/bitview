# bitview for VS Code

`.bv` ファイルのための VS Code 拡張機能。マーケットプレイスには公開しておらず、手元でパッケージにして入れる。

- ハイライト: HTML 要素の関数、定義した関数、組み込み関数（`map`・`concat`）、キーワード、引数の型、レコードのキー、フィールド、文字列、コメントを色分けする。
- 編集: `;` のコメントの切り替え（Cmd+/）、括弧の補完、`entry-list` を1語として扱う単語の区切り。
- 定義へ移動（F12、Cmd+クリック）: 関数名は、開いているファイルが属するプログラムの `.bv` から定義を探す。genbit と同じく、最も近い祖先の `views/` の配下全体を1つのプログラムとする（`views/` の外では、ファイルのあるディレクトリ）。フォルダを開かずにファイルだけを開いても使える。`defn-` で定義した関数は、そのファイルの中でだけ定義へ移動する。引数名は、それを宣言した関数の引数へ移動する。`.` の後のフィールドと `:` の後のレコードのキーは対象外。
- 型: 型の名前の上で定義へ移動すると、ホストが名前を付けた型の宣言へ移動し、ホバーで中身を表示する。宣言は、設定 `bitview.typesCommand`（既定は `genbit types`）を、`views/` を含むディレクトリで実行して得る。出力は読み取り専用の文書として開くので、ファイルに書き出した宣言のように、ホストの型とずれることがない。組み込みの型（`String`・`Bool`・`Flow`・`Phrasing`・`Metadata`）は、ホバーで説明を表示する。コマンドは信頼したワークスペースでだけ実行する。
- 参照を検索（Shift+F12）: 関数なら同じプログラムの全 `.bv` から（`defn-` の関数ならそのファイルから）、引数ならその関数の中から、名前を使っている箇所を探す。定義の名前の上で Cmd+クリックしても参照の一覧が出る。同じ名前の引数が隠している箇所、フィールド、レコードのキー、文字列とコメントの中は含まない。
- アイコン: `.bv` ファイルに `<λ>` のアイコンを付ける（HTML の山括弧と、関数を表すラムダ）。使っているファイルアイコンのテーマが `.bv` 用のアイコンを持たない場合（標準の Seti など）に表示される。
- シンボル: アウトライン、ファイル内のシンボル（Cmd+Shift+O）、ワークスペースのシンボル（Cmd+T）。

定義の検出は `(defn 名前 [` と `(defn- 名前 [` の正規表現で行う。`defn` の関数は1つのプログラムの `.bv` で名前空間を共有し、`defn-` の関数はそのファイルの中で同じ名前の `defn` の関数を隠す。そのため、名前と呼んでいるファイルから定義が1つに決まる。ワークスペースのシンボル（Cmd+T）だけは、ワークスペースの全 `.bv` を対象にする。

## インストール

```sh
cd editors/vscode
npx @vscode/vsce package --no-dependencies --skip-license -o bitview.vsix
code --install-extension bitview.vsix
```

更新したときも同じ手順で入れ直す。
